# Управление установкой приготовления моющих средств 🔧

## Описание
В рамках тестового задания была разработана программа управления установкой приготовления и дозирования моющих средств.  
Алгоритм реализован на языке **ST** в **CodeSys 3.5** для ПЛК **OWEN 210**.  
Для наглядности также была выполнена **визуализация технологического процесса**.

## Логика работы
Запуск алгоритма осуществляется по переднему фронту переменной управления пуском. 
Остановка (все клапаны закрыты, насос остановлен) по заднему фронту этой переменной.
Алгоритм работы установки состоит из нескольких последовательно выполняемых этапов. 
Переход к каждому следующему этапу осуществляется только после полного завершения предыдущего. 

## Этапы алгоритма:
1. Заполнение водой.
Путем управления клапаном V1 заполнить емкость водой до уровня L1.
2. Добавление щелочи в бак.
Путем управления клапаном V2 подавать щелочь в емкость в течении 7 сек.
3. Опустошение бака.
Перекачать из бака приготовленный моющий раствор насосом Н1 до уровня ниже L2.
Алгоритм должен учитывать следующие аварийные ситуации:
- если на этапе №1 (Заполнение водой) бак не заполнился за 10 сек. ошибка неисправности 
клапана V1
- если на этапе №3 (Опустошение бака) бак не опустошился за 8 сек. ошибка неисправности 
насоса Н1
В случае возникновения любой аварийной ситуации алгоритм установки должен 
остановиться, закрыть все клапаны, остановить насос. 
В случае повторного запуска после аварийной остановки переменные ошибок должны 
сбрасываться при старте.

## Входные параметры алгоритма:
- переменная управления пуском/остановкой алгоритма
- переменная состояния датчика уровня L1
- переменная состояния датчика уровня L2
## Выходные параметры алгоритма:
- переменная управления клапаном V1
- переменная управления клапаном V2
- переменная управления насосом Н1
- переменная наличия ошибки неисправности V1
- переменная наличия ошибки неисправности Н1

## Результат
Реализована последовательная логика управления, контроль аварийных ситуаций и визуализация работы установки. ✅
