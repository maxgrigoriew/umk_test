# 🔧 Управление установкой приготовления моющих средств

## Описание
В рамках тестового задания была разработана программа управления установкой приготовления и дозирования моющих средств.  
Алгоритм реализован на языке **ST** в **CodeSys 3.5** для ПЛК **OWEN 210**.  
Для наглядности также была выполнена **визуализация технологического процесса**.

## Логика работы
Запуск алгоритма выполняется по переднему фронту сигнала пуска, остановка — по заднему фронту.  
Установка работает поэтапно: заполнение бака водой, подача щелочи и опустошение бака насосом.  
При отсутствии воды за заданное время или при ошибке насоса алгоритм останавливается и фиксирует аварию. ⚠️

## Результат
Реализована последовательная логика управления, контроль аварийных ситуаций и визуализация работы установки. ✅
